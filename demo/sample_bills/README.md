Demo inputs. `synthetic_*.png` are FICTIONAL bills generated by this project (not real documents; results on them say nothing about real-world accuracy). `restaurant_receipt_owner_screenshot.png` is a screenshot supplied by the project owner; `cafe_receipt_cc0.pdf` comes from the CC0 `my_receipts` collection. The last three files are deliberate failure cases: a blank page (OCR finds no text), a corrupt PNG and an unsupported .txt.

`real_best/` - 13 REAL bills (one per expense category: bus, electricity, flight, food, fuel, gas, hotel, internet, miscellaneous, parking, train, transport, water), chosen from the held-out Task A test split (never trained on) as the best performers: for each category the candidate with the correct Task A label, highest confidence (0.989-1.000) and most Task B fields. Sources: project-owner collection, CC-BY-4.0 Indian grocery GST set, MIT ReceiptBench (real personal receipts - keep internal). Real documents of the new tax-evidence types (rent receipt, Form 16, ...) do not exist in this project; those samples are synthetic and live in `demo/sample_bills_new_categories/`.
